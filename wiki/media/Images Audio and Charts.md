## Summary

Images Audio and Charts covers visual and media assets that improve blog comprehension, trust, distribution, and eligible structured data.

## Media rules

- Every image must clarify the article.
- Every chart needs a dated data source.
- Every generated visual needs review before publication.
- Alt text describes useful information, not keyword stuffing.
- Captions should identify data source and date when relevant.
- Video schema applies only to visible video content.
- Product media rules apply only when product content is present.
- Media variants should preserve claim scope across channels.

## Source posture

- Use Google Images guidance for image search requirements.
- Use Google Video guidance for video SEO requirements.
- Use structured data guidance before adding media markup.
- Use original data sources for charts.
- Keep external asset publishing outside V1.
