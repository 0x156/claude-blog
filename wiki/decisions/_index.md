# Decisions Index

Decision notes record policy choices, approval state, risk, rollback trigger, and source basis.

## Required Fields

| Field | Rule |
|---|---|
| Owner | Name a role or person accountable for the decision. |
| Approval status | Use proposed, approved, rejected, or superseded. |
| Risk level | Use low, medium, high, or blocker. |
| Rollback note | Name the source or condition that reverses the decision. |
